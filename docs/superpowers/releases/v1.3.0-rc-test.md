**Known issue (operator: non-blocking).** After a switch MoSDX → Patched Tunics, the screen looked
wedged. Log: the switch succeeded, Tunics reached `Simulation started`, then logged `Simulation
finished` / `engine: exited (0)` 5.36 s later, and the launcher returned to waiting for a pick —
leaving the last frame on screen. Tunics' language menu calls `sol.main.exit()` on Escape
(`menus/language.lua:78`) and `controls.cfg` maps Start → Escape for that quest, so a Start press
there quits the quest (inferred; button presses are not logged). OSD Load Quest recovers (rewriting
`Solarus.s0` relaunched Tunics). Separately, stopping MoSDX on that switch hit an OpenAL
`LockLists` assertion (exit 134); the launcher proceeded normally.
